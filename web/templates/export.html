Használat

sha256sum -c SHA256SUMS                       # ellenőrzés
gunzip -k m3-archive.sqlite.gz                 # kicsomagolás
sqlite3 m3-archive.sqlite 'SELECT title, year FROM programs ORDER BY year LIMIT 5;'
  • m3-archive.sqlite.gz: a teljes adatbázis (benne a teljes szöveges index és az elérhetőségi előzmény). Egyben biztonsági mentés is.
  • schema.sql: az adatbázis sémája és az oszlopok leírása (magyarul és angolul). Ebből üres adatbázis hozható létre.
  • m3-programs.csv.gz: táblázatkezelőbe való. A szöveges cellák, amelyek =, +, - vagy @ jellel kezdődnének, egy ' jelet kapnak az elejére, hogy a táblázatkezelő ne értelmezze képletként (a CSV-injekció ellen). A pontos adat a JSONL és az SQLite fájlban van.
  • m3-programs.jsonl.gz: soronként egy JSON objektum, pontosan az API szerkezetével.
